# 小简 Markdown 格式参考

整理或修改简历时阅读本文件。小简使用 Markdown 表达内容，再由模板决定颜色、字体和版式；可直接从 [简历骨架](../assets/resume-template.md) 起稿。骨架中的示例与占位符不代表用户事实。

## 姓名、意向与联系方式

```markdown
# 姓名

**求职意向：目标岗位**

手机号码：13800000000 | 电子邮箱：name@example.com | 现居地：城市 | GitHub：https://github.com/username
```

姓名使用一级标题，求职意向单独成行并加粗。联系方式放在同一段，用半角 `|` 分隔；只填写用户提供的信息，缺少的联系方式可省略。网站或作品集建议使用 `网站：https://...`，GitHub 使用 `GitHub：https://github.com/...`。

## 模块与经历

模块使用二级标题，如「个人优势」「教育背景」「工作经历」「实习经历」「项目经历」「专业技能」。按用户经历和岗位选择模块，不需要凑齐全部模块。

每段经历使用三级标题，信息用 `|` 分列，日期用英文半角方括号。标题各列按书写顺序排版，三列分别居左、居中、居右；日期可在最前、中间或最后，日期旁的 `|` 可省略。

```markdown
## 教育背景

### 本科 - 计算机科学与技术 | 某大学 [2020.09 - 2024.06]
- 核心课程：按实际情况填写

## 工作经历

### 前端工程师 | 某公司 [2024.07 - 至今]
- **开发职责：** 写清负责的工作、采用的方法与真实结果。

## 项目经历

### [2023.09 - 2024.03] 某项目 | 项目负责人
- **项目贡献：** 写清个人职责，避免把团队成果全部归于个人。
```

使用 `[YYYY.MM - YYYY.MM]` 或 `[YYYY.MM - 至今]` 表达时间。不把日期当成 Markdown 链接，不用中文全角方括号。时间未知时在草稿中标记待补充，不猜测日期。

经历下可写简短概述，职责与成果用 `-` 无序列表。用 `**关键词：**` 引导，突出真实行动和结果；有已知数据时保留量化成果，没有数据时使用准确的定性表述。

## 技能、强调与分页

技能按领域用加粗标签归纳，例如 `**前端开发：** Vue 3、TypeScript`。重点文字用 `**加粗**`，小简还支持 `**【高亮重点】**`。

需要强制换页时，单独成行写 `\page`。智能一页会保留手动分页符；用户希望压到一页时，检查手动分页是否符合其意图，不自行删除。优先使用标题、段落和列表，不靠表格、空格对齐或内联 CSS 模拟版式。

默认交付纯 Markdown 正文，不添加会被当作简历内容的开场白、排版解释或安装命令。操作说明与简历正文分开提供。
