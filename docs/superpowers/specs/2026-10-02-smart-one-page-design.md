# 智能一页 (Smart Fit to One Page) 功能设计规范文档

## 1. 概述与设计背景

### 1.1 背景
在简历编辑过程中，用户常遇到两种典型的排版失衡问题：
1. **内容微溢出**：写了 1.1~1.3 页，第二页只有孤零零的几行文字，打印浪费且版面不整洁。
2. **内容过局促**：经历内容本身足够支撑一整页，但因字号设得过小、间距压缩得过紧，导致整张简历只占据了上半部 2/3，底部出现大量不美观的空白。

### 1.2 目标
为 max-md2cv 打造“双向自适应智能一页（Global Bounded Auto-Fit）”：
1. **全局定界自适应**：在【舒适上限（Comfort Max）】与【安全下限（Safe Min）】之间，通过算法自动探索出最饱满且刚好满足 1 页的最优参数解。
2. **微溢出时优雅收缩**：优先收紧间距，适度微调行高与边距，守住 11px 正文字号底线，体面收纳为 1 页。
3. **过局促时自然舒展**：当排版过于紧凑时，自动向舒适上限舒展（字号恢复到 14px~14.5px，间距自然展开），恰好撑满整页。
4. **极少内容防大字报**：当内容极少时，严格止步于舒适上限，绝不夸张放大，保持自然留白。
5. **内容严重超量兜底**：当极限最小参数仍大于 1 页时，呈现最紧凑排版，并弹出 Toast 建议精简文字。

## 2. 界面与交互设计

### 2.1 按钮位置
- **位置**：位于预览面板底部栏（`PreviewPane.vue` 的 `preview-footer`）左侧操作区，**放置在「覆盖模板」按钮的前面**。
- **布局顺序**：`[智能一页] [覆盖模板] [恢复默认] ...... [共 X 页]`
- **视觉风格**：遵循 Soft Minimalist 规范，采用次级操作按钮样式。
- **状态流转**：
  - 默认态：Material Symbols `auto_fix_high`，带 hover 极简微光；
  - 计算中：Material Symbols `progress_activity` 旋转动效，按钮禁用，防止快速连击。

### 2.2 操作反馈规范 (ElMessage)
- **极限超量无法单页**：`ElMessage.warning("内容超出单页上限，已呈现最紧凑排版，建议适当精简文字")`
- **自适应舒展撑满（原排版偏紧）**：`ElMessage.success("已自适应优化为饱满舒适单页排版")`
- **自适应收缩至单页（原排版溢出）**：`ElMessage.success("已通过智能算法自适应为最佳单页排版")`

## 3. 双向全局定界参数模型

### 3.1 舒适上限与安全下限约束表

| 优先级梯队 | 参数 Key | 作用 | 舒适上限 (Comfort Max, λ=0) | 安全下限 (Safe Min, λ=1) | 步长 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Tier 1 (间距类)** | `paragraphSpacing` | 段落块间距 | **8px** | **1px** | 1px |
| | `h2MarginTop` | 模块大标题上边距 | **14px** | **4px** | 1px |
| | `h2MarginBottom` | 模块大标题下边距 | **7px** | **2px** | 1px |
| | `h3MarginTop` | 经历标题上边距 | **10px** | **3px** | 1px |
| | `h3MarginBottom` | 经历标题下边距 | **4px** | **1px** | 1px |
| | `personalHeaderSpacing`| 个人信息间距 | **10px** | **4px** | 1px |
| **Tier 2 (行距与边距)**| `lineHeight` | 行高 | **1.6** | **1.25** | 0.05 |
| | `marginV` | 上下页边距 | **11mm** | **8mm** | 1mm |
| **Tier 3 (字号类)** | `fontSize` | **正文字号** | **14.5px** | **11px** (严格底线) | 0.5px |
| | `dateSize` | 日期字号 | **14px** | **11px** | 0.5px |
| | `h3Size` | 经历标题字号 | **16px** | **12px** | 1px |
| | `h2Size` | 模块大标题字号 | **20px** | **15px** | 1px |
| | `h1Size` | 姓名标题字号 | **28px** | **20px** | 1px |

### 3.2 分层单调映射函数 $\mathcal{F}(\lambda)$
定义统一排版强度因子 $\lambda \in [0, 1]$：
- **$\lambda \in [0, 0.4]$**：字号与行高保持舒适上限，优先微调 Tier 1 间距；
- **$\lambda \in (0.4, 0.7]$**：间距保持最小，字号保持舒适上限，微调 Tier 2 行高与页边距；
- **$\lambda \in (0.7, 1.0]$**：间距与行高保持最小，微调 Tier 3 字号至安全底线（含正文字号 11px）。

---

## 4. 算法流程与二分探测机制

1. **第 1 步：极限最小探测 ($\lambda = 1.0$)**：
   - 若 `minPages > 1`，说明内容严重超量，直接赋予极限紧凑参数并触发 Warning 提示。
2. **第 2 步：舒适上限探测 ($\lambda = 0.0$)**：
   - 若 `maxPages <= 1`，说明内容在舒适上限下已能完美容纳在单页内（例如原排版过紧导致底部大面积留白），直接赋予舒适上限参数并触发 Success 提示。
3. **第 3 步：6 次迭代二分搜索 ($\lambda \in [0.0, 1.0]$)**：
   - 寻找满足 `pageCount <= 1` 的最小 $\lambda$（即最舒展饱满的解）。
   - 6 次迭代收敛精度达 $1/64 \approx 1.5\%$。
4. **第 4 步：留白回填优化 (Vertical Relaxation / Redistribution)**：
   - 当二分搜索成功将全部内容收纳进单页后，往往因为尾部大块折行（如技能模块）跳回第 1 页，导致底部留出若干厘米的冗余空白。
   - 算法通过 `relaxOnePageCandidate` 再次进行轻量级步进探测：在保持 `pageCount === 1` 的硬约束下，将多余空白均匀反哺给行高（从 1.25 恢复至 1.30）和标题/段落间距。
   - 彻底解决“字号过小、排版过挤但底部空出一大截”的排版失衡问题，使整张 A4 纸真正达到饱满平衡状态。
