# v0.1.4 Release Notes

发布日期：2026-10-04

## 概览

`v0.1.4` 是一次涵盖排版能力增强、工作区与多格式导出拓展、模板库丰富、AI 与写作辅助，以及独立 CLI 工具链落地的重量级版本更新。

本次版本重点解决了用户在简历排版中最常遇到的“内容略微溢出导致多余空白页”痛点，推出了智能一页自适应排版；同时将导出能力从 PDF 拓展到高分辨率图片，并重构了工作区导出文件管理。此外，新增了沉稳方块与斜角徽章两款新模板、支持经历三列布局与全新商务色系，并为终端用户和智能体生态提供了独立的 CLI 命令行工具。

## 主要更新

### 1. 智能一页排版自适应（Smart One-Page Auto-Fitting）

- **自动测算与紧凑压缩**：针对简历内容在 1.1~1.3 页左右的常见情况，一键按黄金比例微调字号、间距与行高，无损压入单页，消除尴尬断页。
- **单页智能页脚隐藏**：当简历排版最终为单页时，自动隐藏底部页脚页码，视觉更干净自然。

### 2. 导出能力全方位升级：图片导出与统一导出管理

- **高分辨率图片导出**：桌面端除 PDF 导出外，现已支持导出高清晰度 PNG 图片，便于在移动端、聊天软件或招聘平台快捷分享。
- **统一工作区导出管理**：工作区侧边栏重构并整合导出文件管理，用户可直接在工作台内浏览、定位、重命名及删除已导出的 PDF 与图片文件。
- **Web 端体验优化**：Web Playground 优化导出引导流程，并新增导出后的 Star 鼓励与反馈交互。

### 3. 全新内置模板与排版深度定制

- **新增沉稳方块模板 (`business-block`)**：模块化方块标题设计，信息层级鲜明、视觉庄重沉稳，适合资深技术专家与商务管理人才。
- **新增斜角徽章模板 (`slant-badge`)**：现代动态斜切徽标排版，兼具视觉辨识度与专业克制美感。
- **支持经历三列布局**：工作/项目经历标题支持“公司/组织 - 职位/身份 - 时间/地点”三列并列排版，空间利用更高效。
- **经历标题顺序灵活调整**：模板 Schema 与样式支持调整经历标题元素排布与紧凑度。
- **精选商务主题色库**：预设调色盘重构为 15 款低饱和、高质感的商务色系（商务深蓝、冷静蓝灰、科技青绿、墨绿色、勃艮第红等），专业气质更突出。

### 4. 编辑器写作辅助与 AI 提示词赋能

- **Markdown 语法快速指引**：编辑器工具栏内置语法指南弹窗，常用语法一目了然，新手也能零门槛上手。
- **AI 润色提示词一键复制**：内置精调的简历结构化整理与深度润色 Prompt，支持一键复制至剪贴板，方便搭配主流大模型打磨简历文本。

### 5. 独立命令行工具与 Agent Skill (`@max-md2cv/cli`)

- **独立命令行工具 `md2cv`**：新增 `@max-md2cv/cli` 包，支持在终端、CI/CD 与无桌面服务器环境中直接将 Markdown 简历渲染为 PDF、按页 PNG 与元数据 JSON。
- **共享浏览器渲染器**：沉淀独立的 `packages/resume-renderer` 包，打通无头浏览器（Playwright）与渲染流程。
- **Agent Skill 支持**：发布 `skills/md2cv`，方便外部智能体快速集成与自动化调用简历渲染服务。

### 6. 品牌资产与文档全面升级

- **全新视觉图标**：升级桌面端 App Icon、Favicon 与品牌 Logo，统一柔和极简设计美学。
- **文档体系焕新**：全面重构 `README.md`，更新《模板创建指南》，规范社区贡献与自定义模板流程。

## 升级说明

- **配置兼容性**：完全向后兼容旧版工作空间中的 Markdown 文件与自定义样式配置。
- **桌面构建要求**：桌面端继续基于 Tauri v2 + Rust 构建，Windows 平台采用 NSIS 安装器；CLI 工具基于 Node.js 20+ 与系统可用 Chromium/Edge 浏览器。
