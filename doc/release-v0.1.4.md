# v0.1.4 Release Notes

发布日期：2026-10-06

## 概览

`v0.1.4` 重点提升排版效率与导出能力：推出智能一页自适应排版、支持图片导出与统一导出管理、新增两款商务模板，并正式发布独立命令行工具（CLI）与 Agent Skill 协作生态。

---

## 主要更新

### 🚀 新增功能

1. **智能一页排版自适应**
   - 简历内容轻微溢出（约 1.1~1.3 页）时，一键微调排版参数无损压入单页，避免尴尬断页；单页排版自动隐藏页码。
   - 独立 CLI 同步支持 `--one-page` 参数，无需修改 Markdown 原始内容即可完成一页压缩。

2. **支持高清图片导出与统一管理**
   - 桌面端新增 PNG 高清图片导出，便于手机阅读和移动端求职沟通。
   - 侧边栏重构导出管理，支持集中浏览、定位、重命名及删除已导出的 PDF 和图片。

3. **全新商务模板与三列排版**
   - 新增两款专业模板：**沉稳方块 (`business-block`)** 与 **斜角徽章 (`slant-badge`)**。
   - 工作/项目经历支持“公司 - 职位 - 时间”三列横向排版，空间利用更充分。
   - 预设 15 款低饱和度高级商务色系。

4. **独立命令行工具 `@max-md2cv/cli`**
   - 支持在终端、服务器与 CI 环境中将 Markdown 简历批量渲染为 PDF、按页图片与元数据。

5. **编辑器指南与 Agent Skill 协同**
   - 编辑器内置简历使用指南，支持一键复制 AI 润色提示词。
   - 发布 `md2cv` Agent Skill，支持接入 Cursor、Claude Code、Codex 等智能体协作修改简历。

---

### 🛠️ 体验与优化

- **外部链接系统浏览器接管**：桌面端点击简历内的外部链接自动调起系统默认浏览器打开，防止因网页内跳转脱离工作台。
- **视觉品牌统一**：更新桌面端图标与 Logo 视觉资产。

---

## 快速上手

- **桌面安装包**：Windows x64 安装程序位于 `src-tauri/target/release/bundle/nsis/`。
- **CLI 命令行**：`npm install -g @max-md2cv/cli` 或 `npx @max-md2cv/cli render resume.md --one-page`。
- **Agent Skill**：`npx skills add max-doo/max-md2cv --skill md2cv --global --copy`。
